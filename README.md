# Kriva Portfolio

Portfolio landing for [Kriva](https://github.com/edronbaton) (Arseniy): 3+ years commercial, adsota.io, PayCrypto, AiCash, SotaMaker.

## Live on GitHub Pages

Best public host for this static site is **GitHub Pages** on this repo:

`https://edronbaton.github.io/portfolio/`

Enable once: **Settings → Pages → Build and deployment → Source: GitHub Actions**  
(or Source: Deploy from a branch → `main` / `/`).

Push to `main` deploys automatically via `.github/workflows/pages.yml`.

For a cleaner root URL (`https://edronbaton.github.io`) use the user site repo [`edronbaton.github.io`](https://github.com/edronbaton/edronbaton.github.io) instead.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`

English by default. Light / dark theme, liquid glass, adaptive layout.
